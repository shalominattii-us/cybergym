# Film room — Omega Omega Omega (staged, not built)

Replay + failure taxonomy generator. Last layer before the genetic jam.

## What it does

1. Replays any session from the ledger (every rep is already persisted —
   film is a view, not new data).
2. Clusters failure tags across sessions into named failure modes.
3. Tracks failure half-life per mode: how long until a coached weakness
   reappears.
4. Emits the one correction the coach layer carries forward.

## Genetic jam layer (beyond Omega Omega Omega)

Populations of athletes evolve across generations; jam events are the
selection pressure. The ledger's per-rep history is the fitness record.
Nothing here is built until sparring ships.
